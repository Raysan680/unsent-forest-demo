# 《未寄出的森林》Demo README

## 1. 项目名称

**《未寄出的森林》**

一款以“纸质剧场 + 森林邮差 + 双视角解谜”为核心的 2.5D 叙事解谜 demo。玩家扮演一名纸偶信使，在一座沉睡的森林中寻找未送达信件的收件人，通过递送信件、调整纸质场景、切换观察视角，让森林重新产生回应。

## 2. 核心创意概念

森林里的邮局已经停摆很久，留下了一批没有送达的信。随着居民之间的联系中断，森林中的道路逐渐淡化，灯光熄灭，声音也慢慢消失。

玩家扮演一名纸偶信使，接手这些信件，寻找收件人，并在送信过程中修复森林居民之间被遗忘的关系。

本作的核心主题是：

```text
一封信的送达，能够改变一段关系，也能改变一片风景。
```

信件不仅是文字，也可能装着一颗种子、一段记忆、一次道歉，或一句未说出口的话。玩家每送出一封信，森林都会以光、声音、道路、植物和居民状态的变化作出回应。

## 3. 核心体验

玩家主要通过两种方式参与世界：

### A. 进入森林

玩家以纸偶信使的身份在森林中行走、探索和递送信件。

玩家会：

- 在森林入口和旧邮局中寻找未寄出的信。
- 与居民交谈，理解他们之间的关系。
- 根据文字、邮戳、泥土、花瓣、声音等线索判断收件人。
- 将正确的信送到正确的人手中。
- 观察森林在信件送达后的变化。

### B. 观看剧场

玩家可以在特定位置切换到“剧场视角”，从外部观察整座纸质森林舞台。

在剧场视角中，玩家不是直接控制角色移动，而是像调整舞台装置一样操作场景：

- 滑动景片，让断开的道路重新连接。
- 翻折纸面，露出隐藏路径。
- 调整灯光方向，照亮被遮挡的线索。
- 移动纸质植物或小桥，改变森林中的通行关系。

双视角共同作用：

```text
角色视角：体验森林、寻找线索、送出信件
剧场视角：观察整体、调整场景、修复道路
```

## 4. 主要交互形式

| 交互形式 | 玩家操作 | 产生的作用 |
|---|---|---|
| 角色探索 | 使用 WASD 移动，靠近物体或居民互动 | 发现居民、信件线索和舞台机关 |
| 交谈与递送 | 与居民对话，选择对应信件并交付 | 了解关系，推动故事与环境变化 |
| 信件整理 | 查看信件内容、邮戳、污渍和折痕 | 判断收件人、信件含义和下一步目标 |
| 双视角切换 | 在指定位置切换角色视角与剧场视角 | 从局部探索转向整体观察 |
| 景片调整 | 在剧场视角中拖动或旋转纸质景片 | 对齐道路、打开入口、改变遮挡关系 |
| 灯光调节 | 调整舞台灯光或月光方向 | 照亮隐藏物体，发现线索或唤醒场景 |
| 环境回应 | 信件送达后，场景产生变化 | 获得新道路、新声音和下一封信线索 |

## 5. 视觉风格

整体方向：

```text
手工纸质剧场 2.5D
```

游戏采用纸偶角色、分层剪纸植物、立体纸板道路与折纸式建筑，呈现一个可以走进去的微缩森林剧场。

### 角色

- 角色是手绘纸偶。
- 保留细碎笔边和纸张纹理。
- 动作带有轻微的关节摆动感。
- 不追求复杂写实动作，而强调纸偶表演感。

### 植物

- 植物采用多层剪纸叠放。
- 使用切边、折痕和纸纤维表现材质。
- 树冠、草丛、藤蔓可以像舞台景片一样展开或移动。

### 道路与建筑

- 道路和建筑采用简化三维结构。
- 表面使用统一的手绘纸质纹理。
- 桥、邮局、树洞、窗户都像纸模一样被搭建在舞台中。

### 远景

- 远处使用绘画背景与森林剪影。
- 前景、中景、远景通过景片投影和遮挡形成层次。
- 保留舞台边框、底座和景片结构，让玩家意识到这是一个可被调整的纸质剧场。

## 6. 色彩与灯光

基础色彩：

- 墨绿
- 苔绿
- 灰绿
- 米白
- 木褐色

视觉焦点：

- 琥珀色灯光
- 暗蓝色阴影
- 微亮的信件
- 纸张暖黄色边缘

情绪变化：

```text
初始：偏冷、偏暗、沉睡
送信后：局部出现暖光、新色彩和声音
```

空间表现方式：

- 通过景片投影制造层次。
- 通过前后遮挡表现森林深度。
- 通过灯光方向引导玩家注意隐藏线索。

## 7. 作品核心亮点

### 1. 双重身份带来的尺度变化

玩家既是森林中的信使，也是能够调整舞台的操作者。

同一个障碍，在角色视角里是一段断路；在剧场视角里则可能是两块没有对齐的纸板。

### 2. 场景结构直接成为谜题

景片滑动、纸面翻折、灯光方向都具有实际作用。

解谜不是单纯点击按钮，而是通过调整纸质舞台结构，让森林道路重新连通，让隐藏线索被看见。

### 3. 递送结果可以被看见、听见

信件送达后，世界会产生明确反馈：

- 池塘响起蛙鸣。
- 树冠缓慢展开。
- 窗灯亮起。
- 小桥重新连接。
- 新道路出现。

玩家能直接感受到信件改变了这片森林。

### 4. 纸张材质与信件主题互相呼应

森林本身像是由信件、旧纸、邮戳、树皮纹理和手写文字组成。

旧桥可能由旧信裁成，树洞中藏着邮戳，树皮纹理中夹着字迹。近距离探索能够发现森林与信件之间的联系。

### 5. 居民故事逐步织成关系网

每个送信任务相对独立，但又会为下一封信提供线索。

玩家最终理解的不只是单个居民的故事，而是整片森林为什么沉寂，以及居民之间未表达的情感。

## 8. Demo 游戏流程

### 序章：沉睡的邮局

场景：森林入口，一间塞满寄不出去信件的旧邮局。

内容：

- 玩家获得邮差包。
- 发现未寄出的信件与残缺地图。
- 学习移动、调查、查看信件和第一次视角切换。

变化：

- 邮局窗户亮起。
- 第一束光照进森林。

### 第一封信：《装着雨声的信》

收件人：干涸池塘里的青蛙。

故事：

- 一位离开的朋友寄来了它们曾经一起听过的雨声。

谜题：

- 在剧场视角中移动树枝道路的景片。
- 让通往池塘的小路重新连接。

递送结果：

- 池塘泛起水纹。
- 蛙鸣响起。
- 周围草纸缓慢展开。

情感重点：

- 被记得与陪伴。

### 第二封信：《没有说出口的道歉》

收件人：住在树洞里的松鼠。

故事：

- 两位朋友因为误会中断往来，信封上的泥土已经模糊。

谜题：

- 调整灯光。
- 显露藏在树后的压痕。
- 结合台词线索找到正确树洞。

递送结果：

- 树洞窗户亮起。
- 连接两处住所的小桥放下。

情感重点：

- 理解与重新沟通。

### 第三封信：《寄给春天的种子》

收件人：住在常青藤花园的年老园丁。

故事：

- 信中装着一颗多年前约定共同种下的种子。

谜题：

- 展开折叠的引水纸槽。
- 移动景片，让水流依次展开。
- 在花园中出现新的道路。

递送结果：

- 花藤沿纸架向上生长。
- 花园中出现新的通路。

情感重点：

- 等待与延续。

### 第四封信：《给下一位信使》

收件人：玩家。

故事：

- 前任信使留下了最后一封信，讲述邮局与森林居民的往事。

内容：

- 玩家回到邮局。
- 回顾之前送出的信。
- 整理一路收集的邮戳。
- 完成最后的路线拼接。

最终反馈：

- 镜头缓缓拉远。
- 完整纸景剧场显现。
- 居民开始把新的信放进邮筒。

情感重点：

- 回应与继续连接。

## 9. 可选探索内容

- 收集邮戳、旧照片和信纸碎片。
- 阅读居民曾经没有寄出的不同对话。
- 寻找藏在树叶、桥面和背景纸上的文字。
- 重访已经发生变化的区域，发现新的小故事。

## 10. UE5 实现建议

本 demo 的实现目标应保持简单可控：

```text
2.5D 场景
+ 纸质材质
+ 角色移动
+ 互动调查
+ 信件 UI
+ 剧场视角切换
+ 少量景片移动
+ 灯光方向调整
```

不建议第一版制作：

- 大地图开放探索
- 复杂 NPC 行为
- 战斗系统
- 背包系统
- 自由建造
- 复杂物理模拟

建议第一版只完成：

```text
一个旧邮局
一条森林小路
一个池塘谜题
一封完整可递送的信
一次视角切换
一次景片调整
一次环境回应
```
